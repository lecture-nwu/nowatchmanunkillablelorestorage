① 저장소 연결

토큰은 이 브라우저의 localStorage에만 저장되며 어디로도 전송되지 않습니다(GitHub API 호출 제외). "Fine-grained token"으로 발급하고 이 저장소에 대한 Contents: Read and write 권한만 부여하는 것을 권장합니다. 불러오기(공개 저장소)만 할 경우 토큰 없이도 가능합니다. 토큰 발급 페이지 열기
